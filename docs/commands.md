# Commands

Commands are instructions you can execute in the Charxed Peel. You can use full form or short form as you like.

- `quit`  
    short form: q
    desc: quit the editor

- `saveas <path>`  
    short form: sa
    desc: save as `path` file.

- `help [doc-name]`  
    short form: h
    desc: goto help

- `edit <path>`  
    short form: e
    desc: goto and edit the file

- `buffer <path>`  
    short form: b
    desc: goto and edit the buffer

- `bdelete`  
    short form: bd
    desc: delete the current buffer

- `smile`  
    short form: /
    desc: print a smile.

- `about`  
    short form: /
    desc: show version info.

- `create <path>`  
    short form: /
    desc: create a file.

- `remove <path>`  
    short form: rm
    desc: delete a file.

- `move <old-path> <new-path>`  
    short form: mv
    desc: rename a file.

- `mkdir <path>`  
    short form: /
    desc: create a directory.

- `rmdir <path>`  
    short form: /
    desc: delete a directory.
